NAME

warren — Cloud Solution Architect, Azure Core, Microsoft South Africa

SYNOPSIS

Designs Azure architecture for sovereign and regulated-industry deployments across EMEA, consulting to enterprise and financial services customers, system integrators, and ISVs. Deep in ExpressRoute, vWAN, AVS/HCX, Azure Local, Azure Arc/hybrid, AKS, and sovereign landing zones. Terraform to Bicep, Kubernetes to firewalls. Delivers technical content at area and EMEA level.

Former Microsoft MVP — Azure and Office 365 (Teams Voice). Open source and cloud networking background; built global grids for global cloud providers before joining Microsoft. Long-time podcaster and YouTuber, including the Cloud Architects Podcast.
